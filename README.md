# Brewery-Sim

Brewery-Sim is now guided by the batch-driven craft drama direction documented in [docs/project-dev-direction.md](docs/project-dev-direction.md).

The active design target is: build a brewery people care about, one risky, memorable batch at a time.

Previous design and implementation notes have been archived under [docs/archive/2026-05-29-pre-batch-driven-direction](docs/archive/2026-05-29-pre-batch-driven-direction).
