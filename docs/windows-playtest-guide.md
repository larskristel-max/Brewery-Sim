# Old Stables Windows playtest

Thank you for testing this early management-game build.

## Start

1. Extract the entire ZIP before running it.
2. Open `Old-Stables-Playtest.exe`.
3. Windows may identify the build as unsigned. Only continue if you received the ZIP from the Old Stables team and its SHA-256 matches the value supplied with the build.
4. Customize the Brewmaster. The story prologue can be skipped if you want to reach management play quickly.

The build does not collect or transmit analytics.

## Controls

- Mouse: select equipment, workers, contracts, batches, and decisions.
- Space: pause.
- 1, 2, or 4: set the estate clock speed.
- On-screen `12x`: accelerate long waits.
- Escape: clear equipment focus.
- Save and Load: preserve the current campaign on this Windows account.

## Test target

Please complete the first two brewing weeks, then play the Week 3 **Brewery in Motion** plan.

During Week 3:

1. Respond to both contract opportunities.
2. Lock a production plan.
3. Select batches from the live production board.
4. Assign workers while equipment, fatigue, stock, and deadlines compete.
5. Reach the production council.

Do not try to make the “correct” choice. Play the plan that makes sense to you.

## Feedback questions

1. Which contracts did you accept, reject, or renegotiate, and why?
2. At the busiest moment, which batch had priority?
3. What was the main bottleneck: a person, station, ingredient, keg, cash, or deadline?
4. Did fatigue, station wear, and deadline risk make sense before you assigned work?
5. Was there a moment when you knew what you wanted to do but could not find the control?
6. Did the final contract and council results match what you expected?
7. What would you change first?

Please include a screenshot and the approximate in-game day when reporting a confusing moment.
